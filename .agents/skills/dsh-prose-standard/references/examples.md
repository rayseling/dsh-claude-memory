# 蒸馏示例

> 搬自 DeepSeek Harness `dsh-prose-standard/references/examples.md`，保留与宿主无关的条目。用来识别支配原则，不是文本模板。"均衡"指在该位置以最少的解释保住每个承重命题。

## 保住每个事实从句

**原文**："协调器小心地按会话串行化写入，在 dispose 完成前刷掉缓冲事件，并把后端失败报告给调用方。"

**删过头**："协调器串行化持久化。"

**均衡**："协调器按会话串行化写入，在 dispose 完成前刷掉缓冲事件，并把后端失败报告给调用方。"

删装饰和重复，不删命题。主体、按会话的范围、dispose 顺序、失败可见性是四个独立事实。

## 明确的 skill 范围限制是功能

**删过头**："读源码，自行判断。"

**均衡**："本 skill 是指导，不是完整清单。超出点名检查的地方自行判断；已写明的要求仍然适用。"

**写过头**：几段论证清单为何不能替代独立推理。

保留明确的限制，因为它改变 agent 应用流程的方式。删重复的说服，不删护栏。

## 操作指南保留动作与验证

**删过头**："给工具加测试。"

**均衡**："单元级测试注册与销毁，通过真实加载路径调用工具，渲染输出变化时加快照。验证断言观察的是外部结果，不是模型的自述。"

**写过头**：示例代码里已经可见的每个 fixture 和断言的走读。

保留测试层级、必需动作、真实入口、可观察的验证。删 fixture 叙述。

## 保住所有权与时序

**删过头**："teardown 时取消 provider 的工作。"

**均衡**："运行时在释放子作用域之前请求 provider 取消；provider 仍负责在 dispose 完成前 join 自己的 worker。"

**写过头**：实现 teardown 用到的每个 promise 和回调的时间线。

主体、顺序、所有权转移点、完成保证是独立的事实从句。

## 定位复杂代码而不叙述它

**删过头**："worker realm 支持。"

**均衡**："拥有 worker realm 及其宿主桥。realm 初始化只执行一次；dispose 终止 worker 并拒绝之后的调用。协议理由见 worker 隔离 Agent Note。"

**写过头**：对下方每个类和辅助函数的逐段预览。

保留模块的角色、依赖、职责、非显然的生命周期行为。链接架构理由，让代码展示本地控制流。

## 公共文档包含失败

**删过头**："返回 realm 全局对象。"

**均衡**："返回已初始化的 realm 全局对象。初始化未完成或 realm 已 dispose 时抛错。"

throws 和状态前置条件是调用方可见的契约事实。

## 安全边界可能需要一个具体例子

**写过头**：插件可能滥用的每个服务和每个假想攻击的清单。
