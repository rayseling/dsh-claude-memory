# 泄漏示例

> 搬自 DeepSeek Harness `dsh-trim-cot-leakage/references/examples.md`。用来识别支配原则，不是文本模板。本文件刻意引用泄漏措辞作校准材料——探针排除本 skill 的目录，这里的措辞不是别处的许可。

## 死引用

### 有已提交所有者的决定序号

**泄漏**："斜杠输入按可见目录解析（decision 21）。"

**修后**："斜杠输入按可见目录解析——纯文本引用决定，归属输入状态机笔记 `.agents/notes/implemented/architecture/yyyy-mm-dd-input-machine.md`。"

序号在 HEAD 无处解析；决定的名字和所属笔记路径可以。每个文件至少点一次所属笔记路径（能链就链），之后可只用可检索的名字。

### 没有所有者的决定序号

**泄漏**："注册表拒绝重名（decision 7：名字是扁平的，无命名空间）。"

**修后**："注册表拒绝重名；名字是扁平的，无命名空间。"

没有已提交产物拥有"decision 7"，引用删掉——但它的事实从句（扁平名字）重述为独立成立，不随引用一起删。

### 审计条目编号

**泄漏**："渲染是纯函数：同一快照，同一字符串（audit R3）。"

**修后**："渲染是纯函数：同一快照，同一字符串。"

仓库里没有审计文档；编号是零命题的会话速记。

### 未提交草稿的节号

**泄漏**："分层按设计（v2 §3.2）：`src/core/` 是纯核心。"

**修后**："分层：`src/core/` 是纯核心。"

没人提交过的草稿的 `§N` 不可解析。对比："按 RFC 9110 §10.1.5 转义"保留——外部标准按设计在仓库外解析；自带 § 编号的已提交文档也可以按节引用。

### 计划阶段标签

**泄漏**："`src/client/` 是壳（T4）；P-I 迁移拥有适配器。"

**修后**："`src/client/` 是壳；适配器在 `src/client/adapters/`。"

阶段标签索引一个从未落地的计划。用那个阶段产出的东西替换标签。

## 栈与 PR 视角

### 持久散文里的栈位置

**泄漏**："未来的远程后端实现这个接口（sandbox 后端是本栈后面的 PR）。"

**修后**："远程后端可以实现这个接口而不改渲染层。"

持久散文看不见栈。保留扩展点契约；未完成工作的家是 PR 本身、`TODO` 或 issue。

### README 里的"本 PR"

**泄漏**："本 PR 给会话列表加了游标分页。"

**修后**："会话列表按游标分页。"

README 活得比任何 PR 都久；把机制写成当前事实。

## 变更叙述与版本戳

### 带 PR 号的战争故事

**泄漏**："颜色以前来自 `--widget-*` 令牌，但没有东西定义它们，所以总是渲染回退值；别名令牌修了这个（PR #88）。"

**修后**："颜色来自别名令牌；未定义的令牌渲染回退值。"

两个活着的事实都幸存——当前机制和持续存在的失败行为——用现在时重述。bug 的传记属于 PR 和它的 Agent Note。

### 删除叙述

**泄漏**："`probe` 字段随删除一并没了；徽章现在走通用投影对。"

**修后**："徽章使用通用投影对。"

从没见过 `probe` 的读者从它的缺席学不到任何东西。与已删除的过去对比的"现在"是版本戳。

### 修好的回归 → 反事实现在时

**泄漏**："这里以前会把多字节标签双重编码。"

**修后**："没有字节长度守卫，多字节标签会双重编码。"

回归钉以点名守卫的现在时反事实幸存；"以前会"把它钉在仓库考古上。

### 索引式版本戳

**泄漏**："本版批量渲染是同步的；异步路径是路线图工作。"

**修后**："批量渲染是同步的。"（推迟住在调用点的 `TODO(widget-batch):`。）

"本版 / v1 / 今天"合并那一刻就过时。Agent Note 变更章节里的历史阶段名（"第一版交付了 X"）是当前状态安全的；索引式形式永远不是。

## 评审编排

### 评审结论写成散文

**泄漏**："评审时否掉：缓存解析后的 spec。我们保持每次调用解析。"

**修后（放进 Agent Note 的备选方案节）**："**缓存解析后的 spec。** 否决：spec 依赖每次调用的 cwd，按请求键缓存会返回过期的根。"

备选方案这个文体是被允许的家；评审者和轮次不是理由的一部分。

### 草稿序号

**泄漏**："截至本笔记 v5，加载器也校验清单。"

**修后**："加载器校验清单。"

implemented 笔记写已交付的现实；它自己的修订史在 git 里。

## 对评审者的辩护

### 为一个 cast 辩护

**泄漏**："这个 cast 是安全的——SDK 构造了这个对象，它只是没把可选项声明得够严。"

**修后**："SDK 构造这个对象时填满每个可选项；声明的类型比运行时保证松。"

写出维护者不能破坏的不变量。"它只是…"是在回答 HEAD 上没人提出的反对。不变量在代码里可见就删注释。

### 诉诸评审权威

**泄漏**："这是对的，因为 reviewer 确认了包装顺序。"

**修后**：（删除；包装顺序写在函数的 `@returns` 里。）

正确性断言引用不变量或测试，永远不引用人。

## 复述与推导

### 控制流叙述

**泄漏**："先规范化标签，然后截断，然后包装。"

**修后**：（删除。）

注释下面三行代码说的是同一件事。

### 测试走读

**泄漏**："这个测试创建一个会话，发两条消息，等第二条回复，然后断言日志有四条。"

**修后**："两次往返必须恰好产生四条日志——投影去重了共享前缀。"

只留非显然的断言理由；走读复述了测试体。

## 含糊与计划残留

### 没标记的推迟

**泄漏**："先急切渲染大概没问题。"

**修后**：（删除；推迟已有 `TODO(widget-batch):` 标记。）

没有所有者的含糊是计划残留。没有标记就写一个（`TODO(name): 按动画帧合并`），而不是留着含糊。

### 含糊的尺寸

**泄漏**："64 KiB 缓冲对大多数情况应该够了。"

**修后**："64 KiB 容纳观测到的最大帧（48 KiB）并留余量；更大的帧在 `decode` 里响亮失败。"

用实际边界和超出时的失败行为替换含糊。

## 工作语言串台

**泄漏**："The renderer runs on the client 端; see the 设计稿 for spacing. ---- 私有 ----"

**修后**："The renderer runs on the client side; spacing follows the Figma frame `widget-badges`."

工作语言碎片和会话分隔符是转录残留。Figma 帧名保留：按设计在仓库外解析的外部来源。

## 行为可见的候选

**可疑**：某个导出的文档句写着"目前可用"，而生成器把这句复制进模型可见的目录。

**错**：只改源句，或只手改生成的目录。

**对**：追源头的生成扇出，改所有者，重新生成每个派生物，更新拥有它的可运行快照。GUI 字符串要附仓库要求的行为证据。授权范围内没有拥有它的用例时，不改并报告推迟。

## 保留项

### Issue 引用在任何面都持久

**保留**："上限适用于完整的渲染值，包装器也算（issue #1470 负责后续）。"

无辅助的清理删掉了它，理由是 issue 引用属于 Agent Notes。方向错了：issue 从任何面在 HEAD 都可解析，"#N 负责后续"是 README 里推迟工作的允许之家。Agent Notes 和复盘额外允许的是引用*已合并的 PR* 作证据。

### 死的点名不是"点名所有者"

**删除**："widget 接缝上的徽章渲染器（见 widget-rendering RFC）。"

无辅助的清理把它当"按主题点名所属文档"保留了。判据是可解析性不是形式：没有已提交文件叫"widget-rendering RFC"，指针是死的。有已提交所有者就改指过去；否则删。

### 抑制理由

**保留（修正后）**：`// eslint-disable-next-line no-non-null-assertion -- 单元素字面量保证下标 0 存在。`

理由从句是必需散文。写的理由是假的（原文说"上面的循环守卫证明帧存在"而附近没有循环）就改理由；永远不删。

### 实测边界

**保留**："深度上限（实测：512 层嵌套 ≈ 0.15s 同步；4096 阻塞循环）。"

测量把常量钉住防止无知的重调，"实测"标识这是数据不是猜测。

### 运行时的 old / new 不是变更历史

**保留**："旧连接排空后新连接才接受。"

这里的"旧 / 新"命名交接期间的两个活对象，不是仓库状态。变更叙述禁令针对仓库历史，不针对生命周期词汇。

### 运行时的自然时间不是版本戳

**保留**："今天是几号？"

提示词问的是运行时时钟；"今天"不对比仓库状态。因为文本到达模型，任何改写仍需要拥有它的行为证据。

## 删过头的坑

下面每个坑都在原始清理里真实发生并被评审抓住。删之前先列出段落的命题。

### 把义务翻成背书

**原文**："这些直接注册是待迁移到 slot 的例外。"

**删过头**："这些直接注册是被允许的例外。"

**对**："这些直接注册是待迁移到 slot 的例外。"

"待迁移"是义务；"被允许"祝福了现状。删减在缩短的同时翻转了句子的情态。

### 把假设提成已交付的功能

**原文**："未来基于 IPC 的 shell 继承执行器并覆写 `spawn`。"

**删过头**："基于 IPC 的 shell 继承执行器并覆写 `spawn`。"

**对**："假想的基于 IPC 的 shell——目前不存在——会继承执行器并覆写 `spawn`。"

只删未来标记把设计示意变成了"这个类已交付"的断言。明确标记假设，而不是只去掉将来时。

### 把真事实和周围的记录一起删掉

**原文**："门禁提示叙述了检查顺序；提示文本也是 `verify-doc-typecheck` 编译的对象。"

**删过头**："…"（整句当叙述删掉。）

**对**："提示文本是 `verify-doc-typecheck` 编译的对象。"

半句是叙述，另半句是承重的耦合。命题共享一行时删从句，不删句子。

### 保留数字却丢掉测量来源

**原文**："4 MiB 上限是实测的：最大的生成 `py-types` 模块 3.1 MiB。"

**删过头**："上限 4 MiB；最大的生成 `py-types` 模块 3.1 MiB。"

**对**：保留"实测"。

没有"实测"，3.1 MiB 读起来像定义而不是观测，没人会在提上限前重新测量。
